# 本科生科研辅助工具

大一程设课大作业。本人不是CS相关专业的，项目由我进行各子流程设计及相关项目文档撰写，具体代码几乎全部由AI生成，并我进行多轮测试，功能目前已经比较完善了，欢迎使用。

它可以实现 **详细完整且自动化** 的一套流程：
你选定学校和学部->抓取官网页面->获得导师列表，研究方向->你选择某一方向后通过内置关键词表进行该领域权威综述查找与解读->生成该领域前沿综述汇总/概貌文件->你选定一位导师->你确认各流程是否执行->流程查找该导师所有论文（通过ORCID,crossref复核）->获取全文（需要你有基于IP的机构订阅，否则可能无法获取部分文章，只能拿到摘要）->翻译（可选）->生成解读卡（没有AI味且十分详细）->反向查找该导师代表作或其他文章参考文献中的有价值文献，进行整理，输出文档及打分->本地调用我基于qwen3-0.6B微调的小模型抽取导师研究方向关键词，生成词云图谱及研究方向聚类图谱->制作简介PPT

用法：下载整个项目文件夹，将你的agent工作目录设为它，给出学校及学部，要求它按照skill.md执行即可，记得关注执行进度。注意：解读，翻译部分比较烧token，无需使用GPT6价格较高的模型，DS 4.1,Qwen 3.8 Flash，思考强度低即可做到很好。
