# GB/T 7714—2015 参考文献著录模板

> 用于生成《XX_论文列表.md》。作者多于 3 位取前 3 位加 `et al.`；每条附 DOI 与原文链接。

## 一、期刊论文（最常见）

**中文文献**
```
[序号] 主要责任者. 题名[J]. 刊名, 年, 卷(期): 起止页码. DOI: xx. 原文链接：https://doi.org/xx
```

**外文文献**
```
[序号] LIU B, SHIOYAMA H, AKITA T, et al. Metal-organic framework as a template for porous carbon synthesis[J]. Journal of the American Chemical Society, 2008, 130(16): 5390-5391. DOI: 10.1021/ja7106146. 原文链接：https://doi.org/10.1021/ja7106146
```

**著录细则**

| 情形 | 处理 |
|---|---|
| 作者 ≤ 3 位 | 全部列出 |
| 作者 > 3 位 | 前 3 位 + `, et al.`（中文文献用 `, 等`） |
| 无页码，有文章号 | 用文章号代替页码，如 `2021, 9(7): 2001025` |
| 无卷期 | `刊名, 年: 页码` |
| 网络首发/无卷期页 | 标注 `[J/OL]` 并给 DOI 与访问日期 |
| 综述 | 同期刊论文格式（可加注"综述"） |
| 无 DOI | 注明"（ORCID 记录；暂未检索到 DOI）" |

## 二、署名位次标注（本流程特有）

每条末尾标注本人署名位置，便于判断贡献度：

```
…… 原文链接：https://doi.org/xx ｜本人署名：第一作者
…… 原文链接：https://doi.org/xx ｜本人署名：末位作者（通常为通讯作者）
…… 原文链接：https://doi.org/xx ｜本人署名：第 2 位作者
```

## 三、文件组织建议

```markdown
# <作者名>（<英文名>）论文列表

> 作者：……（单位、职称）
> ORCID：https://orcid.org/xxxx-xxxx-xxxx-xxxx（数据来源说明）
> 著录格式：GB/T 7714—2015

## 阶段：2006–2009（博士阶段，XX 组）
[1] ……
[2] ……

## 阶段：2015– 至今（独立建组）
[3] ……
```

## 四、字段来源对照

| 字段 | 权威来源 | 备注 |
|---|---|---|
| 标题 / 期刊 / 年 / 卷 / 期 / 页 | **Crossref API** | 出版社直接注册，最权威 |
| 完整作者列表及顺序 | **Crossref API** | 用于判定本人署名位次 |
| 成果是否属于本人 | **ORCID 页面**（`Works (N of M)`） | 去重后的权威集合 |
| 是否 OA / 全文链接 | **Unpaywall API** | `best_oa_location.url_for_pdf` |
| 摘要 | Crossref / Semantic Scholar / 出版社页（CDP） | ACS、Elsevier 常不注册摘要 |
