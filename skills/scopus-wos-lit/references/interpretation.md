# 摘要翻译、解读与细分方向

这一阶段是**理解**，不是改写。翻错、写空、编造细分方向，都会让后面的检索跑偏。

## 1. 摘要翻译

### 1.1 硬要求

- **完整翻译**，不是要点摘录；不得只译第一句。
- 保留数字、单位、基因/蛋白名、统计量（`HR 1.32, 95% CI 1.05–1.66` 原样保留）。
- 专业术语全文一致：同一概念第一次出现时给“中文（English）”，之后统一用中文。
- 不添加原文没有的因果、评价、建议。
- 不把“综述认为”写成“研究证明”。
- 摘要缺失时写 `[WARN] 未取得摘要`，不要根据标题臆写。

### 1.2 写法

推荐按摘要原结构走：

1. 背景/问题（1–2 句）
2. 范围与方法（综述类型、纳入文献、检索策略）
3. 主要发现（按主题合并，保留关键数字）
4. 结论与展望（1–2 句）

### 1.3 常见错误

| 错误 | 后果 |
|---|---|
| 只译结论 | 读者无法判断证据强度 |
| 把 review 的“可能”译成“证实” | 夸大证据 |
| 丢掉样本量/效应量 | 无法比较 |
| 中英混排且术语不统一 | 后续检索词混乱 |
| 机翻后不校对 | 出现“菌群”与“微生物区系”混用 |

## 2. 解读

每篇 3–5 条，建议固定四段：

1. **研究问题与范围**：这篇综述回答什么、不回答什么。
2. **证据基础**：纳入多少研究、以哪类证据为主（RCT/队列/动物/体外）、有无 Meta 分析。
3. **主要结论**：作者明确支持的 2–3 条结论；区分“一致”与“仍有争议”。
4. **局限与启示**：作者自述局限 + 你识别出的偏倚（选择偏倚、发表偏倚、人群外推）。

写作要求：

- 用“该综述认为/汇总了/指出”，不要用“证明了”。
- 有数字就写数字；没有数字就写证据类型。
- 不要把“未来方向”当成“已实现”。

## 3. 细分研究方向

### 3.1 从单篇归纳

- 每篇 2–5 个，必须能在该篇摘要/全文中找到支撑句。
- 命名格式建议：**研究对象/因素 + 机制或结局**（如“某暴露与某结局的关联”“某通路在某疾病中的作用”）。
- 不要把“综述本身的主题”原样抄成一个细分方向。
- 不要把同一方向拆成多个近义项凑数。

每条写成：

```json
{"name": "由本文归纳的方向", "evidence": "摘要中支撑它的原句或要点"}
```

### 3.2 跨综述汇总

- 合并同义/近义方向；保留 3–8 个。
- 每个方向至少被 1 篇综述支撑；标注支撑综述。
- 如果某方向只来自 1 篇且该篇证据等级低，标 `note` 说明。
- 汇总不是“把所有单篇方向求并集”，要体现领域结构：主线、分支、争议点。

### 3.3 禁止

- [PROHIBIT] 在综述尚未阅读时预写细分方向。
- [PROHIBIT] 把示例方向写进项目文档或模板。
- [PROHIBIT] 用 emoji 做层级装饰；用 `-`、`1.`、`###`。

## 4. 校验

```bash
python lq.py reviews digest-check --tasks digest.tasks.json --filled digest.json
```

校验项：

| 项 | 阈值 |
|---|---|
| 每篇 `abstract_zh` | ≥ 60 字符，非占位符 |
| 每篇 `interpretation` | ≥ 2 条，合计 ≥ 100 字符 |
| 每篇 `sub_directions` | ≥ 2 条，每条有 `name` |
| 汇总 `sub_direction_map` | ≥ 3 条（不足只告警） |
| `summary_zh` | ≥ 200 字符（不足只告警） |
| emoji | 出现即告警，改用 `[OK]`/`[WARN]` |

有 error 时不要生成最终报告；先补全。

## 5. 示例（虚构，仅示格式）

```json
{
  "id": "doi:10.0000/example",
  "abstract_zh": "该综述汇总了近十年关于某暴露与某结局的研究，纳入 42 项队列与 6 项随机对照试验。多数队列显示暴露水平较高者结局风险升高（HR 1.2–1.5），但干预试验的效应较小且异质性高。作者认为关联较为一致，因果关系仍受混杂与测量误差限制。",
  "interpretation": [
    "研究问题：梳理某暴露与某结局的流行病学与干预证据。",
    "证据基础：以队列为主，干预试验数量少、随访短。",
    "主要结论：关联方向一致，但效应量在不同人群中差异明显。",
    "局限：暴露测量多依赖自报，残留混杂难以排除。"
  ],
  "sub_directions": [
    {"name": "某暴露的剂量-反应关系", "evidence": "综述用一节讨论不同暴露水平的风险梯度"},
    {"name": "某干预在特定人群中的效果", "evidence": "干预试验主要集中在某年龄段"}
  ]
}
```

## 6. 写作风格

- 中文、学术、克制；不用营销词。
- 段落短，一句话一个意思。
- 数字与单位之间留空格；英文缩写首次出现给全称。
- 不用表情符号；提示统一 `[OK]` `[WARN]` `[STOP]`。
