# 质量检查表（Interpretation Quality Checklist）

前六条是**硬规则**，违反任一条即重写；随后是**分档检查**与**加分项**。

---

## 一、硬规则（所有档位，必须全过）

### ☐ 1. 语气与证据对齐

逐个动词回查原文，按强度分级落位：

| 级别 | 中文 | 英文 |
|---|---|---|
| L1 强 | 证明、证实、确定、鉴定出、揭示 | demonstrate, establish, identify, reveal |
| L2 中 | 表明、显示、说明、指出、支持 | show, indicate, illustrate, support |
| L3 弱 | 提示、暗示、指向、能够、可能、有望、潜在 | suggest, implicate, can, may, potential |

**常见越界**：

- ❌ `illustrate` → 「证明了」　✅ → 「说明了」
- ❌ `suggest potential` → 「有望成为」　✅ → 「提示了…潜在」
- ❌ `associated with` → 「导致了」　✅ → 「与…相关」
- ❌ `genetically nominated` → 「决定性调控因子」　✅ → 「遗传学上被指定的调控因子」

> 判定方法：把中文译回英文，看是否比原文强。强了就是越界。
> **L1 不因为篇幅短而获得升级许可**——这是最常见的误用。

### ☐ 2. 数值原样引用

- [ ] 未换算（`28,279` 不写成「近三万人」）
- [ ] 未四舍五入（`91 个` 不写成「约 90 个」）
- [ ] 单位、有效数字、基线、条件齐全（**L1 的"取舍"是删，不是改**）
- [ ] 每个数字都能在原文中找到

### ☐ 3. 已验证结论 vs 作者主张

- [ ] 有数据/实验支撑的才进结论
- [ ] 展望、推测、未做的设想归入待验证问题
- [ ] 结论段里没有出现「未来」「有望」「将进一步」

### ☐ 4. 术语首现中英对照（每档各自一次）

- [ ] 每个专业术语首次出现时给出中英对照：`胎儿血红蛋白（HbF）`
- [ ] 同一术语在全篇只对照一次，之后一律用缩写
- [ ] **各档是独立文档**：L2 不能假设读者读过 L3
- [ ] 基因/蛋白符号（BACH2、NRF2、HBG1）与核苷酸基序（UCAU）裸写即可

### ☐ 5. 缺口具名

- [ ] 缺口段写的是"不知道什么"，不是"研究还不够多"
- [ ] 收束段的"补缺口"落点点名了**洞的位置**与**缺的证据类型**
- [ ] 全篇没有出现「具有重要意义」「众所周知」「取得了显著成果」

### ☐ 6. 非臆造

- [ ] 没有原文未出现的数字
- [ ] 没有原文未出现的机制
- [ ] 没有原文未出现的主张（尤其「首次」「重大突破」）
- [ ] 拿不准的内容留空，没有用印象补全

---

## 二、分档检查

### ☐ L1 精简档

- [ ] **无误差项**（`±`）、无置信区间、无 p 值
- [ ] **无样本量**（`N = …`）
- [ ] **无图表引用**（图 3c / 表 2 / Supplementary）
- [ ] **无实验步骤**（凝胶迁移、免疫染色、重采样、测序流程…）
- [ ] 一句话定位只讲"做了什么 + 发现了什么"
- [ ] 主要成就 2–4 条，条目化而非长句
- [ ] 关键数字 2–5 个，且都是**结论性**数字
- [ ] 篇幅 ≤ 500 汉字；表行 ≤ 120 字
- [ ] 表行内每格可独立阅读

### ☐ L2 详细档

- [ ] **保留误差项**与样本量（读者正是要看稳不稳）
- [ ] 实验过程**一句一个手段**，不写成实验记录
- [ ] 「数量不变、特征改变」的两侧都写出
- [ ] **排除性证据已写**（对照实验、独立性、阴性结果）
- [ ] 局限 2–4 条
- [ ] 收尾落在认知价值 + 出口两处
- [ ] 篇幅 400–700 字（上限 1100 汉字）

### ☐ L3 完整档

- [ ] 导语含五要素（时间 / 机构 / 期刊 / 英文原题 / 团队）
- [ ] 动词串逐级深入，非三个并列动词
- [ ] 有**设问推进**（用一次设问从"是什么"到"为什么"）
- [ ] **先排除再聚焦**（先说没变的是什么）
- [ ] 定位式断言含限定语
- [ ] 收尾三落点齐（补缺口 / 拓认知 / 给出口）
- [ ] **证据强度声明**已写（明示作者推测用词）
- [ ] 原文的自我限定（"仅是提示性的"一类）已跟到解读里
- [ ] 篇幅 800–1500 字（上限 2600 汉字）

---

## 三、档间一致性（多档产出时必查）

- [ ] **包含关系**：L1 的每条事实都能在 L2 与 L3 中找到
- [ ] **语气同级**：同一发现的动词强度三档一致，不因档位升高而变强
- [ ] **数字一致**：同一数字三档写法相同，无换算式转述
- [ ] **措辞沿用**：低档直接沿用高档已定的措辞，不为凑长度改写

> 递增的是**细节量**，不是**断言强度**。这条最容易被违反，
> 因为"表格要好看"会诱使作者把 L1 写得比原文更肯定。

---

## 四、加分项

### ☐ 7. 排除性证据已写出（L2/L3）

- 「并不依赖于【经典通路】」
- 「不明显影响【应当不受影响的指标】」
- 「在功能上独立于【已有机制】」

### ☐ 8. 因果链显式

- [ ] 用「从而」「进而」「因此」连接因果
- [ ] 一句一个论断，没有把两件事塞进一句

### ☐ 9. 读一遍检查

- [ ] 只读 L1 的一行，能否判断这篇值不值得读
- [ ] 只读 L2 的卡片，能否复述这篇做了什么、凭什么是真的
- [ ] 只读 L3 的收束段，能否说出缺口在哪、发现值多少

---

## 五、自动校验

```bash
# 档位检查（篇幅上限 + 该档禁写项）
python scripts/check_interpretation.py 解读.md --tier L1

# 额外逐个核对数字是否真在原文里
python scripts/check_interpretation.py 解读.md --tier L2 --source 原文.txt

# 机器可读报告 / 让警告也失败
python scripts/check_interpretation.py 解读.md --tier L3 --json --strict
```

校验器覆盖：硬规则 1（部分）、2、4、5、6，以及全部分档检查。
**它查不到**：语气校准的逐处判定、机制是否忠实于原文、**档间一致性**
（需要把多档一起比对）。这三项仍需人工。

---

## 六、退回重写的触发条件

出现以下任一情况，不要修补，直接重写该段：

1. 结论段里出现展望词；
2. 出现原文没有的数字；
3. 某一档的语气强于原文一级以上；
4. 缺口段是空话，找不到本文填的是哪个洞；
5. 排除性证据存在但整段略去；
6. **L1 里出现误差项或实验步骤**——说明它是把 L3 缩写出来的，不是重写的；
7. **多档之间语气不一致**。

> 修补会让标准在段落之间漂移。重写一段比通篇不一致便宜。
