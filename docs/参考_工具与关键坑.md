## 3. 工具清单

### 3.1 数据源 / API（**优先级最高 —— 零风控风险**）

| 工具                           | 用途                                                                | 调用要点                                                                  |
| ------------------------------ | ------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| **`web_fetch`**        | 抓作者主页、搜索页                                                  | 首个入口；国内高校主页可直接抓                                            |
| **`web_search`**       | 定位 ORCID、核实作者归属                                            | 搜`"<姓名>" <单位> ORCID`                                               |
| **ORCID 公共 API**       | 快速拉取成果列表                                                    | `https://pub.orcid.org/v3.0/<ORCID>/works`；注意含重复条目              |
| **ORCID 网页（经 CDP）** | **权威成果列表**（去重后）                                    | 页面显示`Works (N of M)`，需翻页；比 API 更准                           |
| **Crossref API**         | 题录核实（期刊/年/卷/期/页/作者）                                   | `https://api.crossref.org/works/<DOI>`；务必带 `User-Agent` 含 mailto |
| **Unpaywall API**        | 判断是否 OA、取 OA PDF 链接                                         | `https://api.unpaywall.org/v2/<DOI>?email=...`                          |
| **Semantic Scholar API** | 补摘要                                                              | `https://api.semanticscholar.org/graph/v1/paper/batch`（POST）          |
| **OpenAlex**             | 补摘要（倒排索引重建）；[WARN] 作者聚合**会过度合并**，须消歧 | `?select=abstract_inverted_index`                                       |

> **分层获取策略**：
>
> | 拿什么                                       | 怎么拿                                                     |
> | -------------------------------------------- | ---------------------------------------------------------- |
> | 元数据（题录 / 作者 / 被引 / 参考文献关系）  | [OK] 直连 API（上表即是）                                  |
> | **摘要**、**综述题录**           | [OK]**直连**（`fetch_direct.py` 多源自动降级）     |
> | 白名单内的开源数据库                         | [OK] 直连（`templates/直连白名单.json`）                 |
> | **原文全文**（PDF / HTML 正文，含 OA） | **必须走 CDP**                                       |
> | 第一层取不到                                 | ->**转 CDP**（`grab_abstracts.py --retry-failed`） |
>
> 完整规则见 § 5.1。**判定分界**：这次请求要和不要拿「论文正文」——
> 要正文必须 CDP；不要正文（摘要/题录/结构化元数据）走第一层直连，取不到再转 CDP。
>
> 浏览器配额仍然是需要节省的资源（多实例 + 站点熔断 + 拟人化间隔是成熟的节流手段），
> 但**摘要是最大宗的浏览器开销来源** —— 把它挪到第一层直连，
> 可以做到**零浏览器占用**（数据见 [实测结果汇总.md](实测结果汇总.md#a-1)）。

### 通用 Chromium CDP 浏览器选择与实例归属

CDP不依赖Edge品牌，支持本机Chrome、Chromium、Edge和自定义构建。浏览器发现优先级为
显式 `--browser` > `PAPER_BROWSER` > `CHROME_PATH` > `EDGE_PATH` > 安装候选；显式无效路径报错，
不静默换浏览器。可以使用已启用远程调试的本机实例，但非本工作目录登记的实例只附着、不认领，
不会在结束时关闭；指定可执行路径时必须能核实其与现有端点匹配。

```powershell
# 本机Chrome；也可用环境变量PAPER_BROWSER让下载器/重启沿用
.\start_local.ps1 scripts/cdp_pool.py up --workdir "<运行目录>" --n 1 --base 9222 --browser "C:/Program Files/Google/Chrome/Application/chrome.exe"
# 自定义Chromium构建（路径只是本机示例，不是默认硬编码）
.\start_local.ps1 scripts/cdp_pool.py up --workdir "<运行目录>" --n 1 --base 9223 --browser "C:/s2/src/out/ReleasePGO/chrome.exe"
.\start_local.ps1 scripts/cdp_pool.py status --workdir "<运行目录>" --base 9222 --span 2
.\start_local.ps1 scripts/cdp_pool.py down --workdir "<运行目录>" --base 9222 --span 2
```

新profile按品牌与exe路径哈希隔离，不把Edge的已有profile交给Chrome。端口就绪还需
Browser.getVersion及DOM.getDocument成功；status记录实际版本、exe、PID、profile和owned。
关闭/重启只针对本目录登记且PID、exe、创建时间、精确端口、profile均匹配的实例；
未登记或所有权不符时拒绝终止。重启默认保留已登记浏览器/参数，不因环境变量变化换品牌。
`fresh`/`renew`新建profile，不删除旧profile；`clean --apply`仅移动旧布局，`--purge`拒绝删数据。

默认保留浏览器沙箱；`cdp_up_nosandbox.py`仅为显式选择的环境诊断兼容入口，
不再由综述下载器优先自动选用。Python虚拟环境/uv本身不等于浏览器无法启动，
应查实际exe、CDP/DOM能力与启动日志，而非按解释器名称断言。

普通Cookie/分类按钮只在限定范围内匹配，检查可见性、启用状态、遮挡、链接动作与挑战标记。
不强制隐藏弹窗/改滚动，不点击验证码，不发送Input.*。`dismiss_consent_report`区分
attempted/clicked/verified/blocked/unchanged；旧bool接口仅实际verified返回true。
分类枚举使用独立标签页、稳定类别身份和内容签名/完成标记；未更新、空类别、超时、
隐藏/禁用等保留partial，不把上一类名单归给下一类。

本地可靠性检查：`selftest_browser_runtime.py`、`selftest_click_logic.py`；
真实浏览器检查：`selftest_consent.py --browser <exe> --port <空闲端口>`，使用独立profile并自行清理。
宿主SendInput的既有政策仍按§5.2，但本地普通DOM测试不能证明验证码像素识别或通行可靠。


## 5. 关键坑与对策（实战经验）

| 问题                                           | 现象                                                                                                                          | 对策                                                                                                                                                                                                                             |
| ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CDP WebSocket 403                              | `Handshake status 403 Forbidden`                                                                                            | 启动加`--remote-allow-origins=*`；并确保旧实例已被杀                                                                                                                                                                           |
| Edge 进程退出                                  | `ConnectionRefusedError 10061`                                                                                              | **多实例池** + 逐篇 TCP 探活 + 自动重启；不要单实例跑长批                                                                                                                                                                  |
| **脚本「死机」**                         | 无输出、长时间不动                                                                                                            | 已修复：所有 CDP 调用带**绝对截止时间**；不再有 `while True: recv()`；`wait_for_manual` 默认关闭                                                                                                                       |
| **误触发 CAPTCHA（形态一）**             | 短页面/勘误页被当成验证页，弹窗空等 15 分钟                                                                                   | 已修复：改用`detect.judge()` 精确判定，**绝不用文本长度当判据**                                                                                                                                                          |
| **误触发 CAPTCHA（形态二）**             | Cloudflare 的 JS 挑战会**自动放行**，但脚本一见 `just a moment` 就放弃 → 把本可自动通过的站点误报为「需人工验证」    | 已修复：新增`settle_challenge()` **宽限期**（默认 25s，`--grace=` 可调）。宽限期内首探到的「请稍候…」空壳正文会在数十秒后自动放行成完整正文（记录见 [实测结果汇总.md](实测结果汇总.md#e-4)）                                                 |
| **泛词误报封禁**                         | 正文含`forbidden` / `blocked by` → 触发全局中止                                                                          | 已修复：封禁用精确短语；模糊词仅「短页面开头」才算数                                                                                                                                                                             |
| 杀进程失败                                     | `Invalid argument/option - 'C:/Program Files/Git/PID'`                                                                      | Git Bash 路径转换所致，用`MSYS_NO_PATHCONV=1 taskkill /PID <pid> /T /F`                                                                                                                                                        |
| **uv 装包失败（换机器常见）**            | `error: Failed to install: …whl` + `Access is denied. (os error 5) at path "…\Temp\.tmpXXXX"`                            | `uv run --with …` 要在**系统 TEMP 里解包**；该目录不可写时代码一个字没改也会失败（本机 Oct-7 核验报告里已有同一条）。把 `TMP`/`TEMP` 指到可写目录即可：<br>`TMP=<可写目录> TEMP=<可写目录> uv run --with … python …`（实测：同一条命令在 `%TEMP%` 受限时报 5 项假失败、换可写目录后 57/57 通过） |
| 中文打印乱码                                   | `UnicodeEncodeError: 'gbk' codec`                                                                                           | 统一用`logutil.py`（内部 `errors="replace"`，不会中断流程）                                                                                                                                                                  |
| 标题含噪声                                     | 混入`check_circle Crossref`、页码                                                                                           | 在`clean_title()` 中统一替换/正则清洗                                                                                                                                                                                          |
| Crossref 限流                                  | 并发时批量失败                                                                                                                | 失败项串行重试 + 指数退避；UA 带 mailto                                                                                                                                                                                          |
| ORCID 条目重复                                 | API 返回 107 条但页面仅 79 条                                                                                                 | **以网页 `Works (N of M)` 为准**，按 DOI 去重                                                                                                                                                                            |
| 付费全文不可得                                 | 出版社订阅墙                                                                                                                  | 明确注明限制；只翻译已获得全文的论文；其余用摘要级信息解读                                                                                                                                                                       |
| **站点在国内根本连不上**                 | SSRN（`10.2139/*`）在中国大陆 IP 段网络层不可达，不是风控问题                                                               | 已固化进`detect.CN_INACCESSIBLE`，选取待办时**直接跳过**，不做无谓重试；在清单中注明「国内 IP 不可访问」                                                                                                                 |
| 触发风控                                       | 短时间大量请求出版社                                                                                                          | 低频拟人化 + 站点熔断（见阶段 E）                                                                                                                                                                                                |
| **重复下载 / 误删已有 PDF**              | 早期文件无年份前缀，被当成「没有」→ 重下；校验失败时删掉同名旧文件                                                           | 已修复：`store.existing_pdf()` 兼容两种命名；`_write_pdf` 只删本次写入的文件                                                                                                                                                 |
| **1 页勘误被误拒**                       | Author Correction 本身就是 1 页                                                                                               | 已修复：`store.validate_pdf()` 放行「1 页且 ≥100 KB」                                                                                                                                                                         |
| 摘要 API 缺口                                  | ACS/Elsevier 不向 Crossref 注册摘要                                                                                           | 用**OpenAlex 倒排索引重建** 兜底                                                                                                                                                                                           |
| 中文 PDF 页数校验                              | 无法用 pdftoppm                                                                                                               | 用`pypdf` 提取文本，统计 CJK 字符数间接验证                                                                                                                                                                                    |
| **改名后重复下载**                       | 题名命名使「按 DOI 找文件」失效，历史去重逻辑失效                                                                             | 新增`.work_cdp/pdf_index.json` 登记表；`store.register_pdf()` 在落盘后写入，`existing_pdf()` 优先查表                                                                                                                      |
| **Ray ID / 429 误判为 IP 封禁**          | Cloudflare 403/429 错误页带 Ray ID → 被判`blocked` → **整轮中止**（曾一次 403 就停掉全部批次）              | 探针新增`SOFT` 名单（经 `hits.softHead` 回传）+ `classify()` 新增规则 5b/5c/5d：Ray ID/限流话术只判 `challenge`（站点级熔断），**不再全局停摆**                                                                    |
| **抓到的是补充材料而非正文**             | AHA/Circ 等站点`links` 首位常是 `suppl_file/*.pdf`（补充材料）或图注页，2 页却通过校验                                    | 下载后校验页数；正文一般 ≥6 页。残缺件改名`【补充材料】…` 保留，用 `history/*.pdf` 或 `/doi/pdf/...?download=true` 重抓                                                                                                  |
| **翻译 PDF 空白/无中文**                 | HTML 未写入中文或字体未嵌入                                                                                                   | `render_html_pdf.py` 退出码 2 = CJK < 50，需回查 HTML；正常输出 `OK pages=… cjk_first_page=…`                                                                                                                              |
| **自编脚本直连抓取原文（含 curl 探活）** | 用`curl -I` 测出版社连通性、或用 `urllib`/`requests` 直下**全文** → 同样触发风控且拿不到内容，还无法纳入流程判定 | **严禁**（§ 5.1 **第二层**）；连通性判断交给浏览器（`detect.navStatus` 即真实 HTTP 状态）。**OA 全文同样走 CDP**。摘要/综述题录/白名单开源库属**第一层**，**允许**直连 —— 边界见 §5.1 分层表 |
| **用 CDP `Input.*` 过验证** | 「CDP 点击`isTrusted=True`，应该能骗过 Turnstile」——**错误**：判定不靠该次点击 | **禁止**用 CDP `Input.*` 过验证（§5.2）；**允许**用**宿主机级 `SendInput`** 点复选框（每篇 ≤3 轮，失败即停）。只点复选框，不点“重试/换题” |
| **浏览器「找不到」时报 WinError 87** | `Popen` 抛 `OSError: [WinError 87] The parameter is incorrect`，浏览器起不来 | 已修复：`cdp_pool.EDGE_CANDIDATES` **剔除空值** —— 未设 `PAPER_BROWSER` / `EDGE_PATH` 时它们是空串，而 `Path("").exists()` 恒为真（指当前目录），会让候选表**假命中**并返回 `""`，`Popen([""])` 即报此错 |
| **检索子进程输出非 GBK 字符** | 阶段 R `search_run.py` 整源 `exit 1`，子进程 stderr 是 `UnicodeEncodeError: 'gbk' codec` | 已修复：给 `paginate.py` 子进程显式设 `PYTHONIOENCODING=utf-8` —— 父进程按 UTF-8 解码，就不该让子进程按**控制台代码页**写 stdout |
| **CDP 可用性探测偶发失败** | `reviews_fulltext` 报「无可用 CDP 实例」，而端口其实正常 | 已修复：`renderer_count` **串行化 + 失败重试**（探测失败 `-1` ≠ renderer 为 0）；仍不稳时用 `--ports 9222,9223` 跳过探测 |
